# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | integer | 否 | 页码，默认 1 |
| `size` | integer | 否 | 每页数量，默认 20 |

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 错误码

| 状态码 | 含义 | 处理建议 |
| --- | --- | --- |
| 400 | 参数格式错误 | 检查 `page` 和 `size` 是否为正整数 |
| 404 | 文档不存在 | 确认文档编号 |
